
# Clean Geological Q&A App (Offline, Concise Output)

## ✅ How to Use:

1. Unzip this folder.
2. Install dependencies:
   pip install -r requirements.txt
3. Run the app:
   streamlit run document_qa_app_clean.py

No API key required. This version uses:
- SentenceTransformer for embeddings
- flan-t5-large for answers
- Strict prompt to keep output concise
